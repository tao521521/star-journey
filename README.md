# 星火征程

GitHub 协作与持续部署配置见 [GitHub与Netlify部署说明](GitHub与Netlify部署说明.md)。这是无需构建的静态项目，Netlify 发布目录为 `dist`，构建命令留空。

纪念中国工农红军长征胜利90周年原创互动学习作品。主题为“九十载长征·代码续星火”。以热烈朱红、暖金、纸张底色和原创木刻风主题插画，连接历史学习与青年行动。

## 运行

- Windows：双击 `启动项目.bat`，需已安装 Python 3。
- 命令行：`python run.py --open`，浏览器访问 http://127.0.0.1:5173 。端口占用时使用 `python run.py --port 5174 --open`。
- 也可以直接打开 `dist/index.html`。全部资源均为本地文件，无需联网即可体验；不同浏览器对 file:// 页面本地保存的支持有差异，正式展示推荐本地服务器方式。
- 停止服务器：在启动窗口中按 Ctrl+C。

## 六个内容板块

1. 启程首页：长征主题视觉与内容入口。
2. 重走长征：九站历史地图、史实、精神解读、教学挑战和集章。
3. 精神挑战：12题知识库，每轮随机抽取最多6题，支持综合、历史和精神专场；含时空排序、星火传讯、机动路线。
4. 红色记忆：六篇人物、军民、精神和征途故事，支持筛选、收藏与阅读记录。
5. 青春接力：五项现实行动清单和最多3000字的本机学习手记。
6. 我的行囊：进度、印记、集章册、文本学习记录导出；完成九站后可下载PNG纪念卡。

## 原创性与素材

界面结构、程序、教学关卡与叙事文案为本项目重新设计。创意研究参考 TapTap《前进之路》的参与式历史学习理念，没有使用该游戏代码、截图、角色、剧情或界面资产。

`dist/assets/long-march-woodcut.png` 为内置 image_gen 工具生成的原创主题艺术插画，不是历史照片。生成方式、完整提示词见 `设计与素材说明.md`。其余视觉由项目CSS/SVG绘制。没有使用商业字体文件或第三方前端依赖。

史料来源可在网页“史料来源与作品说明”查看。内容数据位于 `dist/data.js`，便于团队继续校订与扩充。

## 技术结构

- HTML5 + CSS3 + 原生 JavaScript，无框架依赖、无需构建。
- `dist/core.js`：状态校验、行囊判定、路径规则和集章逻辑。
- `dist/app.js`：页面、交互、对话框、竞答、导出。
- 本地存储：LocalStorage，键为 `xinghuo-journey-v1`。数据只存本机，不自动同步。清除浏览器数据会清除进度，学习记录可先导出。
- 支持电脑和手机自适应布局、键盘焦点、减少动态效果偏好。
- `python run.py` 仅用于本地静态服务，不收集身份信息。
