# 星火征程

- GitHub 私有仓库：[tao521521/star-journey](https://github.com/tao521521/star-journey)
- Netlify 网站：[星火征程](https://creative-melba-512a1a.netlify.app)
- 日常开发目录：`E:\星火征程\star-journey`（原 `xinghuo` 目录保留为旧项目副本）

GitHub 协作与持续部署配置见 [GitHub与Netlify部署说明](GitHub与Netlify部署说明.md)。这是无需构建的静态项目，Netlify 发布目录为 `dist`，构建命令留空。

纪念中国工农红军长征胜利90周年原创互动学习作品。主题为“九十载长征·代码续星火”。以热烈朱红、暖金、纸张底色和原创木刻风主题插画，连接历史学习与青年行动。

## 运行

- Windows：双击 `启动项目.bat`，需已安装 Python 3。
- 命令行：`python run.py --open`，浏览器访问 http://127.0.0.1:5173 。端口占用时使用 `python run.py --port 5174 --open`。
- 也可以直接打开 `dist/index.html`。全部资源均为本地文件，无需联网即可体验；不同浏览器对 file:// 页面本地保存的支持有差异，正式展示推荐本地服务器方式。
- 停止服务器：在启动窗口中按 Ctrl+C。

## 六个内容板块

1. 启程首页：长征主题视觉与内容入口。
2. 重走长征：九站历史地图、史实、精神解读、教学挑战和集章。
3. 精神挑战：12题知识库，每轮随机抽取最多6题，支持综合、历史和精神专场；含时空排序、红色电波·行军通信、机动路线。
4. 红色记忆：七篇人物、军民、精神、征途故事和通信档案，支持筛选、收藏与阅读记录。
5. 青春接力：五项现实行动清单和最多3000字的本机学习手记。
6. 我的行囊：进度、印记、集章册、文本学习记录导出；完成九站后可下载PNG纪念卡。

## 原创性与素材

界面结构、程序、教学关卡与叙事文案为本项目重新设计。创意研究参考 TapTap《前进之路》的参与式历史学习理念，没有使用该游戏代码、截图、角色、剧情或界面资产。

`dist/assets/long-march-woodcut.png` 为内置 image_gen 工具生成的原创主题艺术插画，不是历史照片。生成方式、完整提示词见 `设计与素材说明.md`。其余视觉由项目CSS/SVG绘制。没有使用商业字体文件或第三方前端依赖。

史料来源可在网页“史料来源与作品说明”查看。内容数据位于 `dist/data.js`，便于团队继续校订与扩充。

## 技术结构

- HTML5 + CSS3 + 原生 JavaScript，无框架依赖、无需构建。
- `dist/core.js`：状态校验、行囊判定、路径规则和集章逻辑。
- `dist/app.js`：页面、交互、对话框、竞答、导出。
- 本地存储：LocalStorage，键为 `xinghuo-journey-v1`。数据只存本机，不自动同步。清除浏览器数据会清除进度，学习记录可先导出。
- 支持电脑和手机自适应布局、键盘焦点、减少动态效果偏好。
- `python run.py` 仅用于本地静态服务，不收集身份信息。

## 星火记忆图谱

“重走长征”顶部可切换“历史路线 / 星火记忆图谱”，不增加主导航。地图与图谱共用九站和当前选择；图谱初次打开显示九站，选择后展开该站的事件、人物、故事与精神，右侧（手机端下方）显示历史档案。可返回全部节点、点击关联地点继续探索、打开原有故事与本站挑战。手机可横向滑动图谱，也可使用站点按钮；SVG节点支持 Tab、Enter 和空格。

- `dist/data.js` 的 `chapters[].detail` 保存补充档案，`graph.index` 用真实 ID 索引五类节点；地点保留原 ID，其他节点使用 `event:`、`person:`、`story:`、`spirit:` 前缀。
- 故事引用原六篇内容，人物不重复维护故事；“半条被子”为湖南汝城独立延伸阅读，不绑定九站地点。
- 浏览图谱与档案不写入学习进度；打开故事仍沿用已读/收藏规则，完成挑战仍沿用原集章规则。`dist/core.js` 和 Netlify 配置未改动。
- 第八站统一为“到达吴起镇”（1935年10月19日）；1936年会师分别为甘肃会宁和将台堡（今属宁夏西吉），与中央红军主力长征结束区分。
- 史料核查：原“二万五千里长征”链接返回未找到页，已改引中央党史和文献研究院《红军北上和三军大会师》，并结合长征胜利90周年专题中的大事记和征程资料；陈树湘沿用湖南省民政厅人物资料。未使用新历史图片，原主题插画仍为AI辅助艺术表达，挑战仍为教学模拟。
- 待团队校订：泸定、雪山、草地及1936年会师档案暂不扩写未逐人核实的人物名单，页面明确标注待补充。精神解读为教学阐释；后续可用专题原始文章替换综合专题引用，增加资料粒度。

## 红色电波·行军通信

精神挑战中的原“星火传讯”入口现为“红色电波·行军通信”。先阅读通信背景和设备说明，再操作两部教学电台，依次转移、抵达、架设、试联、确认。新台确认有效联络前，旧台须驻守；完成三次交接获得独立的“红色电波”学习印记。可重试，也可回看历史。

“星火记忆图谱”增加“长征通信史”专题入口，连接电台交替转移、罗若遐、王诤、15瓦哈特莱式发报机及通信人员档案；四渡赤水关联通信保障专题。红色记忆支持“通信档案”筛选、阅读与收藏。

- 史料：中国电信博物馆《黑夜走路的灯笼——长征中的无线电通信》；党建网刊载的中国人民革命军事博物馆文章《长征路上的“灯笼”》；中国科协刊载的中国科学家博物馆王诤介绍。网页均提供原始链接。
- 无线电通信保障与无线电技术侦察分别解释。A/B电台、三次交接、信号线及操作均为原创教育模型；设备图为功能示意，不复原文物外观，不包含真实电文、军用密码或作战指令。
- `dist/core.js` 新增纯函数 `radioInitial` / `radioStep`。沿用存档版本与键名，新增可选 `learningBadges` 数组，旧存档默认空数组；九站 `award` 规则及草地站原有记忆挑战保持不变。阅读数量使用故事实际数量，原有“记忆守护者”仍按原六篇评定；导出记录包含专题印记。


## 交互与视觉优化（P0 / P1）

- 历史地图：Grid按顶部对齐，地图用独立比例约束尺寸。`chapterPanel()` 和 `refreshJourney()` 只更新详情与节点状态，连续选择站点保留地图DOM。地理底图保持SVG比例，时间路线独立绘制；悬停/键盘焦点可预览，已有时间轴可快速定位。已浏览样式仅保留在当前会话，不增加集章。
- 图谱导览：初始右栏显示实时数据统计、湘江人物探索推荐和简短流程；返回全图恢复导览。`recordGraphPath()` 和核心 `relationPath()` 仅沿实际有向关系生成可点击路径，高亮已探索连线。发现提示附来源，不授予认证或挑战印记。
- 知识竞答：`recordQuiz()` 单独保存 `lastQuiz`（正确数、总题数、四舍五入后的分数），同时保留 `bestScore` 的最大值。缺少最新结果的旧存档仍保留最高分、次数与其他记录，不编造上一轮分数。结束时只同步底层成绩卡，再渲染结果弹窗；手机也显示本轮与最高分。
- 错题回顾：本轮答案仅保留在当前页面会话，关闭弹窗后仍可从成绩卡回看；刷新后只保留汇总成绩。带明确 `chapterId` 的历史题可进入对应图谱。自由练习、通信学习印记与九站集章仍分别记录。
- P2未实施：持久探索轨迹、行囊发现卡、青春回应PNG卡、历史与现实对照。本轮优先保证缺陷修复和现有功能稳定。

浏览器验收覆盖1920、1440、1024、768、375像素宽度，地图DOM保留与尺寸不变，多轮成绩83→100→33（最高100）、存档刷新、错题/图谱互跳、前进后退、键盘操作与减少动态效果设置。运行项目原有语法检查和 `node --test tests/core.test.cjs`。
