# 星火征程

纪念中国工农红军长征胜利90周年的互动学习网页。以九站历史探索、红色记忆和协作挑战，连接长征精神与青年行动。

- 代码仓库：https://github.com/tao521521/star-journey （私有）
- 在线网站：https://creative-melba-512a1a.netlify.app
- 开发目录：`E:\星火征程\star-journey`
- 提交材料：本仓库的 `提交` 文件夹。最终文件夹名称由参赛团队调整。

## 本地运行

双击 `启动项目.bat`，或运行 `python run.py --open`，需要 Python 3。端口占用时执行 `python run.py --port 5174 --open`。

也可以直接打开 `dist/index.html`，所有网页素材均在本地。正式演示推荐服务器方式，以获得稳定的浏览器本地存储支持。只有打开外部参考史料链接时才需要联网。

## 内容与交互

|板块|内容|
|---|---|
|启程首页|红色木刻风主视觉，历史、故事与挑战入口|
|重走长征|权威历史路线图，九个坐标按实际通关进度点亮；九站史实、关卡与集章|
|历史关联|以卡片展示地点、事件、人物、故事与精神之间的有来源关系|
|精神挑战|知识竞答、时空排序、路线解谜、三轮通信接力|
|红色记忆|七篇图文故事，支持分类、收藏与已读记录|
|青春接力|现实行动清单与本机学习手记|
|我的行囊|进度、独立学习印记、文本导出与九站纪念卡|

地图保留历史地名和区划，学习节点以中央红军主要历程为线索，延伸到1936年三大主力会师。1935年10月中央红军到达吴起镇与1936年会师分别呈现。教学挑战不改变历史结局，也不按牺牲人数或英雄功绩计分。

导航集中在顶部，手机使用底部导航。地图与章节说明上下排列。数字地图标记仅作学习导航，真实行军路线以历史底图为准；灰色坐标表示待挑战，红色勾选表示已通关，金色外框表示当前浏览的站点。切换站点、阅读史实、答错题或完成自由练习不会增加九站进度；已完成记录在刷新后继续保留。

通信接力沿用队友实现的状态规则：至少保留一部驻守，先行电台完成抵达、架设、试联和确认后才能交接。其学习印记独立于九站集章。自由练习、故事阅读、关联探索和九站完成分别记录。

## 本轮整合

已同步并保留队友的历史档案、关联数据、通信专题、错题回顾和存档迁移。重新整理阅读层级，扩大正文与按钮字号，移除英文装饰和重复说明。关系网络以可直接操作的卡片呈现，切页采用轻量淡入与虚化，并尊重“减少动态效果”设置。

红色记忆封面和正文采用用户提供的主题插画，“雪山草地”原封面保持不变。地图引自中央党史和文献研究院，完整保留图例并可放大。来源、素材对应关系与核查记录见 `素材与史实核查.md`。主题插画均不作为历史照片或人物肖像考证。

## 源码结构

- `dist/index.html`、`style.css`：页面结构与响应式样式。
- `dist/data.js`：史实、题库、人物与有向关联数据。
- `dist/media.js`：封面、正文配图和地图来源。
- `dist/core.js`：存档校验、路线规则、集章、成绩与通信状态机。
- `dist/app.js`：页面、阅读弹窗、交互关卡和导出。
- `tests/`：核心逻辑与素材完整性测试。
- `run.py`：仅使用 Python 标准库的本地静态服务器。

LocalStorage 键仍为 `xinghuo-journey-v1`，旧进度继续兼容。记录只在本机保存，不自动跨设备同步。项目没有账号、收费或数据上传功能。

## 检查与部署

执行 `node --test tests/*.test.cjs` 运行全部检查。GitHub Actions 在推送和拉取请求中自动运行测试。

本项目无需构建，没有 `package.json`。`dist` 是真实源码目录，必须提交。Netlify 从 `main` 自动发布，构建命令留空、发布目录为 `dist`。日常协作流程见 `GitHub与Netlify部署说明.md`。
